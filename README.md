# FModel

Симулятор движения к неподвижной цели на Delphi VCL для Windows.
Регулятор получает измеренный угол с ошибкой и задержкой, шаг времени и текущую угловую скорость.
Истинные координаты, смещение датчика и длина буфера задержки остаются внутри модели.

## Возможности

- PID-регулятор с фильтрацией производной и адаптивной поправкой по интегральной составляющей и угловой скорости.
- Кнопки «Инит», «Старт/Стоп», коррекция смещения датчика кнопками `+` и `−`.
- Автоматическая остановка при начале роста расстояния до цели, отображение минимального промаха.
- Перетаскивание цели и системы координат, изменение масштаба колёсиком мыши.
- Параметры через меню «Файл → Параметры» или `Ctrl+S`, сохранение в INI рядом с EXE.
- Траектория из последних 300 точек, история последних 200 шагов.
- Просмотр состояния модели, P/I/D и выхода регулятора по слайдеру после остановки.

Адаптивная поправка улучшает управление, но не является гарантированной оценкой истинного смещения датчика.
Оценщика задержки в текущем алгоритме нет. Дистанция используется только симуляцией для проверки и автостопа.

## Структура

| Файл | Назначение |
|---|---|
| `uMotionModel.pas` | Движение, неподвижная цель, ошибка и задержка датчика |
| `uGuidanceController.pas` | PID-регулятор и адаптация поправки |
| `uMain.pas`, `uMain.dfm` | Интерфейс, таймер, связь модели с регулятором, история |
| `FModel.dpr`, `FModel.dproj`, `FModel.res` | Проект Delphi и необходимые ресурсы |
| `tests/` | Консольные проверки модели, регулятора и интерфейса |

Модель и регулятор не зависят друг от друга. Их связывает `uMain`:

```pascal
FModel.W := FController.Update(dt, FModel.MeasureAngle, FModel.W);
FModel.Integrate(dt);
```

## Сборка

Проверено с RAD Studio 12, каталог Studio `23.0`, конфигурация `Debug / Win32`.
Откройте `FModel.dproj` в Delphi и выполните сборку. Либо используйте командную строку RAD Studio:

```text
msbuild FModel.dproj /t:Build /p:Config=Debug /p:Platform=Win32
```

Результат: `Win32/Debug/FModel.exe`. Перед пересборкой закройте запущенный EXE.
Локальные настройки, исполняемые файлы и промежуточные результаты исключены из Git.
Ресурс `FModel.res` включён в репозиторий, поскольку нужен для сборки проекта.

## Проверки

В командной строке RAD Studio перейдите в `tests` и соберите нужную проверку, например:

```text
dcc32 -B -NSSystem;Winapi;Vcl -U.. HistoryTest.dpr
HistoryTest.exe
```

Основные проверки:

- `BiasAdaptationTest` — 180 сценариев адаптации, ограничения поправки, отключение и сброс.
- `MotionModelTest` — независимость модели и регулятора, последовательность передачи данных.
- `IntegratorTest`, `DistanceStopTest` — таймер, догон времени и автостоп.
- `HistoryTest`, `TrajectoryTest` — история, просмотр и ограничение траектории.
- `TargetTest`, `ViewSettingsTest`, `ZoomTest` — цель, INI, перемещение и масштаб.
- `RegulatorAudit`, `TuningValidation` — интегратор регулятора и сценарии движения.

VCL-проверки запускаются в Windows. Их INI-файлы и изображения создаются локально и не публикуются.
