# FModel

Исследовательский стенд на Delphi VCL для изучения погрешности углового датчика при движении объекта.
Задача эксперимента — исследовать оценку и компенсацию ошибки измерения, когда показание датчика отстаёт от изменения положения объекта.

Модель задаёт движение объекта и равномерно движущуюся опорную точку, относительно которой формируется угловое измерение.
Постоянная погрешность представлена добавляемым смещением, динамическая — задержкой измерения в кольцевом буфере.
Регулятор получает только измеренный угол, шаг времени и текущую угловую скорость объекта.
Параметры датчика и геометрия эксперимента остаются внутри модели и используются для сравнения результатов.

## Возможности

- PID-регулятор с фильтрацией производной и адаптивной поправкой по интегральной составляющей и угловой скорости.
- Кнопки «Инит», «Старт/Стоп», коррекция смещения датчика кнопками `+` и `−`.
- Автоматическая остановка при начале роста расстояния до опорной точки, отображение минимального расстояния.
- Перетаскивание опорной точки и системы координат, изменение масштаба колёсиком мыши.
- Параметры через меню «Файл → Параметры» или `Ctrl+S`, сохранение в INI рядом с EXE.
- Траектория из последних 300 точек, история последних 200 шагов.
- Просмотр состояния модели, P/I/D и выхода регулятора по слайдеру после остановки.

В текущем алгоритме `AdaptiveAngleCorrection` — поправка измеренного угла, которая подбирается по интегральной составляющей и угловой скорости объекта.
Её соответствие заданному смещению датчика проверяется в эксперименте. Отдельная оценка задержки пока не реализована.
Расстояние до опорной точки служит показателем эксперимента и условием автоматической остановки.

В окне «Файл → Параметры» (Ctrl+S) доступны задержка датчика в измерениях, смещение датчика,
скорость и начальный угол красной точки, коэффициенты PID и все параметры адаптации.
Углы вводятся в градусах, время — в секундах. Задержка 0 отключает задержку;
нулевое время фильтра отключает сглаживание, Ki/Kd = 0 отключают соответствующие составляющие.
Все значения сохраняются в INI. «ОК» применяет их со сбросом расчёта; «Отмена» оставляет прежние значения.
Открытие диалога приостанавливает расчёт. «Сбросить по умолчанию» заполняет поля исходными значениями,
которые сохраняются только после нажатия «ОК».
По умолчанию задержка — 3 измерения, смещение — −20°, скорость красной точки — 50 км/ч,
начальный угол — −10°, Kp = 6, Ki = 10, Kd = 0,5, предел интегратора = 10 рад/с.
В текущем эксперименте сохранена дополнительная поправка движения красной точки `Fi + 3*deg`.
При скорости 0 точка неподвижна. Кнопка «Инит» восстанавливает начальные координаты и движение.
Перетаскивание и диалог параметров задают начальные координаты; в INI сохраняются они, а не положение после расчёта.
Положение обеих точек записывается в историю на каждом шаге.

## Структура

| Файл | Назначение |
|---|---|
| `uMotionModel.pas` | Движение, равномерное движение опорной точки, ошибка и задержка датчика |
| `uAdaptiveRegulator.pas` | PID-регулятор и адаптация поправки |
| `uParameters.pas` | Окно параметров, исходные значения, проверка и сохранение INI |
| `uMain.pas`, `uMain.dfm` | Интерфейс, таймер, связь модели с регулятором, история |
| `FModel.dpr`, `FModel.dproj`, `FModel.res` | Проект Delphi и необходимые ресурсы |
| `tests/` | Консольные проверки модели, регулятора и интерфейса |

Модель и регулятор не зависят друг от друга. Их связывает `uMain`:

```pascal
FModel.W := FController.Update(dt, FModel.MeasureAngle, FModel.W);
FModel.Integrate(dt);
```

## Сборка

Проверено с RAD Studio 12, каталог Studio `23.0`, конфигурация `Debug / Win32`.
Откройте `FModel.dproj` в Delphi и выполните сборку. Либо используйте командную строку RAD Studio:

```text
msbuild FModel.dproj /t:Build /p:Config=Debug /p:Platform=Win32
```

Результат: `Win32/Debug/FModel.exe`. Перед пересборкой закройте запущенный EXE.
Локальные настройки, исполняемые файлы и промежуточные результаты исключены из Git.
Ресурс `FModel.res` включён в репозиторий, поскольку нужен для сборки проекта.

## Проверки

В командной строке RAD Studio перейдите в `tests` и соберите нужную проверку, например:

```text
dcc32 -B -NSSystem;Winapi;Vcl -U.. HistoryTest.dpr
HistoryTest.exe
```

Основные проверки:

- `ParametersTest` — параметры, проверка ввода, сброс, сохранение INI, нулевые I/D и задержка.

- `BiasAdaptationTest` — 180 сценариев адаптации, ограничения поправки, отключение и сброс.
- `MotionModelTest` — независимость модели и регулятора, последовательность передачи данных.
- `IntegratorTest`, `DistanceStopTest` — таймер, догон времени и автостоп.
- `HistoryTest`, `TrajectoryTest` — история, просмотр и ограничение траектории.
- `ReferencePointTest`, `ViewSettingsTest`, `ZoomTest` — опорная точка, INI, перемещение и масштаб.
- `RegulatorAudit`, `TuningValidation` — интегратор регулятора и сценарии движения.

VCL-проверки запускаются в Windows. Их INI-файлы и изображения создаются локально и не публикуются.
